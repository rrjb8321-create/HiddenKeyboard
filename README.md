# Hidden Keyboard — Android

نسخة أولية فعلية من كيبورد أندرويد باسم Hidden Keyboard.

الميزات الحالية:
- كيبورد عربي وإنجليزي.
- وضع عادي.
- وضع إخفاء باستخدام Unicode zero-width بحيث يكون الناتج غير مرئي تقريبًا داخل الرسائل.
- زر لفك الإخفاء.
- زر مسافة، حذف، Enter وتبديل اللغة.
- لا يتم إرسال النص إلى أي سيرفر.

> ملاحظة: وضع الإخفاء الحالي هو **ترميز قابل للعكس** وليس تشفيرًا أمنيًا حقيقيًا.

## بناء APK
افتح المشروع في Android Studio ثم Build > Build APK(s).

كما توجد GitHub Actions في `.github/workflows/android.yml` لتجميع `app-debug.apk` تلقائيًا عند رفع المشروع إلى GitHub.
